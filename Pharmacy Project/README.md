# 💊 Pharmacy Inventory Analysis Dashboard | Power BI Project

## 👨‍💻 About This Project
This project is a business-focused data analysis dashboard built using Power BI for a pharmacy inventory system.  
The main objective is to analyze stock, suppliers, and product performance in order to optimize inventory management, reduce waste, and improve decision-making.

---

## 🎯 Business Problem
Pharmacies often face challenges such as:
- Managing large numbers of products efficiently  
- Understanding inventory value and stock levels  
- Tracking supplier dependency  
- Avoiding overstocking or understocking  
- Making data-driven purchasing decisions  

This project was designed to solve these problems using data analysis.

---

## 🛠 Tools & Technologies
- Power BI (Data Visualization & Dashboarding)
- Excel (Data Cleaning & Preparation)
- SQL (Data Extraction & Querying)
- Python (Optional Data Processing)

---

## 🔄 Workflow (What I Did)

1. Collected pharmacy inventory data  
2. Cleaned and structured dataset  
3. Built relationships and data model in Power BI  
4. Created KPIs and calculated measures  
5. Designed interactive dashboard for inventory analysis  
6. Extracted actionable insights for business improvement  

---

## 📊 Key KPIs

- Number Of Products  
- Average Unit Price  
- Number Of Suppliers  
- Total Inventory Value  
- Available Quantity  
- Average Item Value  

---

## 📈 Key Insights (IMPORTANT)

- 📌 Inventory value shows significant capital tied up in stock, affecting cash flow  
- 📌 Supplier dependency highlights potential operational risk if any supplier becomes unavailable  
- 📌 Product distribution indicates imbalance between high-value and low-value items  
- 📌 Proper stock monitoring can reduce waste and improve efficiency  
- 📌 Data-driven inventory decisions can significantly improve pharmacy performance  

---

## 💡 Business Impact

This dashboard helps a pharmacy to:

- Improve inventory control and reduce waste  
- Optimize purchasing decisions based on supplier/product data  
- Reduce financial risk from overstocked items  
- Improve stock availability and customer satisfaction  
- Support smarter and faster decision-making
